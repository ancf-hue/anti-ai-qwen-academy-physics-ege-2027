# анти-ии квен академия физика егэ-2027

Бесплатный социальный офлайн-проект — тренажёр ЕГЭ-2027 по физике по официальной демоверсии, спецификации и кодификатору ФИПИ.

> 🌐 **Онлайн-версия:** [ancf-hue.github.io/anti-ai-qwen-academy-physics-ege-2027](https://ancf-hue.github.io/anti-ai-qwen-academy-physics-ege-2027/)

## 📌 О проекте

Тренажёр работает в любом браузере без установки, без интернета и без регистрации. Все ответы проверяются локально — ваши данные никуда не отправляются.

### Что внутри

- **26 заданий**: 20 с кратким ответом (часть 1) и 6 с развёрнутым ответом (часть 2)
- **45 первичных баллов**
- **235 минут** на выполнение
- Встроенный таймер экзамена с пресетами (235 / 60 / 30 минут)
- Чек-лист подготовки и подробный план на 25 дней
- Автопроверка для части 1 и честная самооценка по критериям ФИПИ для части 2

## 📚 Структура тренажёра

| Раздел | Задания | Первичные баллы |
|---|---|---|
| **Часть 1 (краткий ответ)** | 1–20 | 28 |
| **Часть 2 (развёрнутый ответ)** | 21–26 | 17 |
| **Итого** | **26** | **45** |
